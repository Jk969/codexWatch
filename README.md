# CodexWatch — 手机上的 Codex 任务指挥台

用微信式的手机 App 随时查看、操控你电脑上正在跑的 Codex 任务:任务列表像聊天列表,任务详情像聊天窗口(实时滚动指令/执行/输出),任务结束手机收到通知,还能直接在手机上发起新任务、追加指令、停止任务。支持多人(邀请码)一起使用。

```
手机 App(APK/浏览器) ──wss──> 云中继(阿里云 al) <──wss── PC 守护进程(Bridge) ──> ~/.codex/sessions
```

---

## ⚡ 三分钟上手(你现在要做的事)

1. **装 App**:把 `dist/codexwatch.apk` 传到手机(微信文件传输助手/QQ/数据线均可),点击安装(允许"未知来源")。
   - 不想装 App 也行:手机浏览器直接打开 **https://pcphone.jingxixi.top/** (可"添加到主屏幕"),功能一致,只是通知依赖浏览器。
2. **登录**:账号 `admin`,密码为部署时生成的强密码(2026-10-11 已轮换;忘记时在服务器执行 `node /root/codexwatch/relay/reset-password.js admin 新密码`)。
3. **验证**:打开 App 应看到「任务」列表里全是这台电脑的历史 Codex 任务。进入 **项目 → 新建任务**，选择项目或电脑文件夹后进入聊天草稿，调整参数并发送第一条指令才会发起任务。

**电脑侧无需任何操作**——守护进程已在本机运行并配置了开机自启(本机浏览器访问 http://127.0.0.1:3599 可预览同一界面)。

### 🔔 通知收不到?必做的一步(国产手机)

App 依赖前台常驻连接收通知(和微信同思路,无需谷歌服务)。请在系统设置里给 CodexWatch:
- 通知权限:允许
- **自启动/后台运行:允许**(小米:锁定后台;华为:启动管理→手动管理全开;OPPO/vivo:允许后台运行)
- 省电策略:无限制

设置后在最近任务里把它**加锁/锁定**,别上滑划掉。1.3.5 起不再持有常驻 CPU 唤醒锁，后台暂停页面计时器并降低心跳频率；任务通知由原生服务处理。手机深度休眠或系统限制后台网络时，通知可能延迟；重新打开时会补收离线期间的通知(云端保留 24 小时)。

## 📱 功能速览

| 位置 | 功能 |
|---|---|
| 任务(首页) | 全部 Codex 会话:**运行中/待处理自动置顶**(浅绿底+状态角标),点开进入聊天式详情;**左滑任务项**可「归档」或「新建任务」(直接进入该项目的新聊天草稿) |
| 任务详情 | 用户指令(右绿气泡)、Codex 回复(左白气泡,流式输出)、工具调用卡片(点击展开参数/输出)、思考摘要、系统事件 |
| **命令授权** | 新任务默认"智能授权":Codex 要执行危险命令时,聊天里出现**授权卡片**(允许/本会话均允许/拒绝/拒绝并停止),同时手机推送"需要你的授权" |
| **运行中提问** | Codex 反问时出现**提问卡片**(选项点选即答/自由输入),手机同步通知;不在线时云端暂存 |
| 输入框 | 给任务**追加指令**:空闲会话立即执行;运行中自动排队(任务结束后依序发送);输入框左侧 ⌥ 按钮=**切换模型与思考程度**(对后续消息生效) |
| 聊天右上 ⋯ | 停止任务 / **任务完成后关机**(延迟5分钟,输入框上方橙色状态条实时显示,点击可取消) / 复制会话ID / **浏览项目文件夹** / 任务信息(模型/Token/目录) / 归档该任务 / 免打扰 |
| 项目文件浏览 | 聊天 ⋯ → 浏览项目文件夹:子目录导航+文件名筛选;**文本预览**(前 64KB,可复制;**Markdown 直接渲染成排版结果**,可一键切回源码)、**图片/视频/音频内置播放**(图片可点开全屏);任意文件**下载到手机**(下载/CodexWatch,≤20MB);APK 内还可**「用其他应用打开」**(apk 可直接调起安装器);只能访问项目目录内文件;新建任务草稿里也可浏览 |
| 归档 | 左滑列表项或聊天菜单归档;已归档任务集中在任务列表底部「已归档」查看、可一键恢复;运行中/待处理任务不可归档;**归档后一旦有新活动自动回到列表**;归档状态保存在手机本地 |
| 项目 → 新建任务 | 选好目录后进入聊天草稿，可调整模型、思考程度和审批模式；右上角菜单调整沙箱，发送第一条指令才创建任务。草稿阶段暂不支持附件和文件引用 |
| 项目 | **联系人式项目列表**(徽标显示运行中/待处理数),点进项目看它的全部任务、一键在该项目发起新任务 |
| 设备 | 绑定的电脑、在线状态、**添加设备**(生成6位配对码,电脑端 `--pair` 绑定) |
| 动态 | 任务总数/运行中/累计 Token/项目分布 |
| 我 | 账号、**邀请用户**(管理员)、通知设置、修改密码、服务器信息、退出登录 |

发起的任务优先以**交互模式**运行(基于 codex app-server:可授权、可提问、可打断、可随时切模型);交互服务不可用时自动降级为 `codex exec` 一次性执行。你在终端/Codex Desktop 里自己开的会话是"外部会话":能看、能排队追加指令,但不能远程停止(无 PID 映射,属正常限制)。

## 👥 多人一起用

1. 管理员:App「我 → 邀请用户 → 生成新邀请码」(初始邀请码已作废,请用 App 生成新的)
2. 同伴:手机装 APK → 登录页点「邀请码注册」→ 输入邀请码 + 自定账号密码
3. 同伴进入后需在自己的「设备」页生成**配对码**,你在电脑上运行一次:
   ```
   cd /d/dev/gpt/codexWatch/bridge
   node index.js --pair <同伴的6位配对码>
   ```
   即可把这台电脑共享给同伴(每人配对自己要用的电脑;你的电脑只有配对过的人能看到)。

## 🖥 电脑端(Bridge)管理

- **已配置开机自启**(注册表 `HKCU\...\Run`,通过 `codexwatch-bridge.vbs` 静默启动)。取消:删除该注册表项或 `D:\dev\gpt\codexWatch\codexwatch-bridge.vbs`。
- 手动前台运行(可看日志):双击 `start-bridge.bat`
- 配置文件 `bridge/config.json`(deviceId/deviceToken/server/name),**请勿泄露**——拿到它就能操作你的 Codex
- 监控范围:近 14 天会话(`--days N` 可调);自动跳过 guardian 等内部子代理会话
- 本机预览:http://127.0.0.1:3599

## ☁️ 服务器端(Relay,在 al 上)

- 服务:`systemctl status/restart codexwatch-relay`(目录 `/root/codexwatch`,日志 `/var/log/codexwatch-relay.log`)
- 入口:https://pcphone.jingxixi.top (nginx→127.0.0.1:35500;证书 Let's Encrypt,已自动续期,原 ClipBridge 配置备份在 `pcphone.jingxixi.top.conf.clipbridge.bak`)
- 数据:`/root/codexwatch/relay/data/relay.json`(用户/设备/配对/离线通知队列,重启不丢)
- 管理员密码重置(忘记时):见下方 FAQ

## 🔒 安全机制(2026-10-11 加固)

- **密码**:scrypt 加盐哈希存储;注册/改密要求至少 8 位;登录失败按真实客户端 IP 限速(10 次失败锁 10 分钟)
- **登录 token**:30 天滑动有效期,过期自动清理
- **设备隔离**:用户只能给自己配对过的设备发指令(WS dev_frame 校验配对关系)
- **配对码**:6 位一次性、10 分钟过期;猜错 20 次锁 IP 10 分钟
- **邀请码**:注册猜错同样限速;初始邀请码已作废,新码请在 App 内生成
- **本机守护进程**:WebSocket 只接受本机页面来源(防公网恶意网页借浏览器操控电脑上的 Codex);静态服务双重目录逃逸校验
- **传输**:全程 HTTPS/WSS(Let's Encrypt,自动续期,HTTP 强制跳转)

## ❓ FAQ

- **App 打开闪退?** 新版已加固(前台服务三级降级+全局异常捕获)。若仍闪退:手机连电脑后 `adb pull /data/data/top.jingxixi.codexWatch/files/crash-log.txt` 把日志发回来即可精确定位。
- **电脑要一直开机**:Bridge 跑在电脑上,电脑睡眠=断连。请在电源设置里把睡眠改为"从不"(接电源时),或至少任务跑着时别睡眠。
- **任务发起后没反应?** 电脑需在线(设备页有绿点);确认电脑上 `codex --version` 可用;查 `start-bridge.bat` 前台日志。
- **忘记 admin 密码**:在 al 上执行 `node /root/codexwatch/relay/reset-password.js admin 新密码` 即可重置。
- **电脑换了网络/重启**:Bridge 自动重连云端,无需干预。
- **多台电脑**:每台电脑放一份 `bridge/` 目录,各自 `--pair` 配对即可,App 里切换查看。

## 🗂 项目结构

```
codexWatch/
├─ bridge/      PC 守护进程(会话监听/解析/codex exec 控制/本地UI服务/云端连接)
├─ relay/       云端中继(账号/配对/消息路由/离线通知),部署于 al
├─ web/         微信式 Web UI(桥本地、手机浏览器、APK 三处共用)
├─ app/         安卓壳工程(WebView+前台服务常驻推送),build-apk.sh 一键出包
├─ dist/codexwatch.apk   ← 装这个
├─ docs/DESIGN.md        产品设计与技术选型
└─ start-bridge.bat / codexwatch-bridge.vbs   PC 启动入口
```

技术要点、事件协议、设计取舍详见 `docs/DESIGN.md`。祝使用愉快 🎉
